# Привет, я Михаил 👋

Я предприниматель, 30 лет занимаюсь торговлей и производством. Когда-то поставил ИИ себе в помощники — сначала на своём бизнесе, потом начал делать это для других.

Три основных направления моей работы: ИИ-автоматизация бизнес-процессов, интеграции (встраивание ИИ в текущие задачи компании) и проверка вайб-кода — разбор решений, которые заказчику написала нейросеть.

Чем отличаюсь. Я не программист, а заказчик, который сам живёт на этих системах: мои конвейеры и боты работают каждый день без присмотра. Бизнес-процессы знаю изнутри — экономику, остатки, рекламу, поставщиков, розницу и маркетплейсы. Поэтому задачу ставлю на языке процесса и денег, а не технологий. И объясняю просто: если делаю инструмент для человека, он открывается двойным кликом и работает без настройки.

Работы — в закреплённых репозиториях этого профиля.

> «Лучший код — это тот, который пользователь не замечает. Он просто открыл файл — и всё работает.»
